SVGO, in Rust

A native port of SVGO 4.1.0 preset-default. All 34 plugins, byte-identical output on 2,478 icons, and it uses every core.

Get it on GitHub

Same output

Every plugin matches JS SVGO byte for byte. A parity check runs on every change.

Fast

A single native binary with no runtime. Folder mode optimizes thousands of icons in about a second.

Drop-in

The same command line as svgo: a file, a folder or stdin. Read the plugin list here.

Install

cargo build --release
./target/release/svgo-rs input.svg -o output.svg
./target/release/svgo-rs -f icons -o out   # a whole folder
cat input.svg | ./target/release/svgo-rs -  # stdin to stdout
